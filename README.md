# jeevikafoundationbest

Separate deployment project for the upgraded Jeevika Foundation site.

## URLs

- GitHub repository: `https://github.com/iamkamlesh18/jeevikafoundationbest`
- GitHub Pages: `https://iamkamlesh18.github.io/jeevikafoundationbest/`

## Scripts

- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run lint`

## Notes

- Local and GitHub Pages both use `/jeevikafoundationbest/...`
- Example routes: `/jeevikafoundationbest/about` and `/jeevikafoundationbest/programs`
- `public/404.html` is included so direct page refreshes work on GitHub Pages
